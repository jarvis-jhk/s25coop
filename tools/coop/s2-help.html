🏰 s25coop needs the original Settlers II

s25coop is built on Return to the Roots, a free remake of the engine of The Settlers II. The graphics, sounds, maps, campaign and intro video still belong to Blue Byte / Ubisoft and cannot be shipped with it — you bring them from your own copy of The Settlers II Gold Edition. You need them only once; updates never touch them.

1. Get the game

The easiest way is the GOG version, DRM-free and cheap:

The Settlers 2: Gold Edition on GOG.com

On GOG, go to your library, pick the game, and under Download offline backup game installers download the Windows installer. You do not need to run it (and you cannot, on Linux).

2. Leave it in your Downloads folder

The s25coop installer looks only in your Downloads folder (it never searches your whole disk). It recognises these files:

GOG installer: setup_the_settlers_2_gold_….exe (for example setup_the_settlers_2_gold_1.5.1_(30319).exe)

Copies of the original CD, as they are named on archive.org:

  • The Settlers II Gold.zip
  • The Settlers II Gold.bin + .cue
  • Settlers_II_The_Gold_Edition_1997.zip
  • siedler2gold.7z
  • Siedler2-Gold_mdf.zip
  • Siedler2-Gold_nrg.zip
  • siedler2.zip
  • Siedler2.bin / SIEDLER2.bin
  • Die Siedler II.img
  • The Settlers II.img
  • Settlers2MASTER.bin
  • Game4U_12_Settlers-II_cd.bin

Also any .zip, .iso, .bin, .img, .mdf or .nrg with “settlers” or “siedler” in its name, and a folder in Downloads that contains the game's DATA and GFX folders. A .7z file needs 7z or bsdtar installed (SteamOS has bsdtar).

3. Start again

Go back to the installer window and choose look again — or simply start s25coop, it looks again by itself. It copies the folders DATA, GFX and VIDEO (about 60 MB) to ~/.local/share/s25coop/S2. After that you may delete the download.

Already have the game installed somewhere?

Copy its DATA and GFX folders (and VIDEO, for the intro) into ~/.local/share/s25coop/S2/ yourself, then start s25coop.

Which version?

Return to the Roots is made for the files of The Settlers II: Veni, Vidi, Vici with the Mission CD, which is exactly what the Gold Edition is. The Settlers II: 10th Anniversary (2006) is a different game and does not work.
